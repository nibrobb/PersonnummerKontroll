# Fødselsnummer-kontrollør

Sjekk om er fødsels- og personnummer er gyldig.

Test gjerne med disse fiktive personnummrene
```
20302740292
23286629318
09231300837
```

Bruk: `pnrkontroll [Personnummer]`

eller bare kall
```bash
./pnrkontroll
```

og skriv inn, eller ta input fra stdin
```bash
cat test-pnr | ./pnrkontroll
```
